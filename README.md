# Fonctionnalités : 
Pour la caméra, choix possible entre la caméra orbitale et la caméra cinématique (qui suit la courbe de Bézier) en cochant le script voulu. La caméra qui suit la courbe fait le tour de la courbe en restant fixée sur un point (le joueur “Asuna”, changeable). Tous les paramètres (vitesse, rotation…) sont changeables sans passer par le script.
Le joueur peut courir, sauter et tirer sur l’ennemi.
L’ennemi se déplace vers le joueur quand celui-ci se trouve dans une certaine zone autour de lui, il l’attaque s’il se trouve au corps à corps.
